# portfolio-sites

Portfólio de layouts e sites. Cada projeto fica em sua própria pasta, com um `README.md` explicando o que é, o status e as ferramentas usadas.

## Projetos

| Projeto | Descrição | Status |
|---|---|---|
| [serena-spa](./serena-spa) | Layout de exemplo para spa e salão de beleza, com fundo animado e liquid glass (marca fictícia) | Exemplo |

## Como adicionar um projeto

1. Crie uma pasta com o nome do projeto (ex.: `nome-do-cliente`).
2. Coloque os arquivos do site e um `README.md` com descrição, status e pendências.
3. Adicione uma linha na tabela acima.
