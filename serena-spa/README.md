# Serena Spa & Beleza

Layout de exemplo para spa e salão de beleza, com fundo animado em CSS e efeito "liquid glass". Marca, endereço, telefone e avaliações são fictícios e servem apenas para demonstração.

## O que tem

- Hero em tela cheia com fundo animado em CSS (degradês em movimento), título grande em serifa itálica e menu em vidro líquido
- Seções de serviços, ambiente, avaliação e contato
- Rodapé em vidro líquido
- Responsivo (desktop e celular) e com animações suaves ao rolar

## Como usar

Arquivo único, sem build. Abra `index.html` no navegador.

Para usar um vídeo próprio no fundo, troque os elementos `.blob` do hero por uma tag `<video>`.

## Ferramentas

- HTML, CSS e JavaScript puro
- Fontes: Instrument Serif e Barlow (Google Fonts)
- Base de design: prompts gratuitos do MotionSites (hero Visual Hero e rodapé Lumina), adaptados

## Pendências para uso real

- Trocar os espaços reservados da seção "Ambiente" por fotos reais
- Preencher endereço, telefone, horários e serviços do cliente, e ligar os botões ao WhatsApp
